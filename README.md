# c2py — транслятор підмножини мови C на flex + bison

Конвеєр:

```
program.c ─► flex (lexer.l) ─► bison (parser.y, LALR(1)) ─► AST
                                                         ├─► sema.c     семантичний аналіз (області видимості, типи)
                                                         ├─► interp.c   обчислення: інтерпретатор AST
                                                         ├─► codegen.c  генерація коду мовою Python 3  ─► out.py
                                                         └─► ast.json + web/index.html  візуалізація (чистий JS + SVG)
```

## Що підтримується (граматика C)

| Категорія | Конструкції |
|---|---|
| Типи | `int`, `char`, `long` (як int), `double`, `float` (як double), `void` |
| Верхній рівень | кілька функцій з параметрами, рекурсія, обов'язкова `main` |
| Інструкції | блоки `{}`, оголошення `int a = 1, b;`, `if / else if / else`, `while`, `for(;;)`, `return`, `break`, порожня `;` |
| Вирази | `= += -= *= /= %=`, `\|\| && == != < > <= >= + - * / %`, унарні `- !`, `++x x++ --x x--`, виклики, дужки |
| Літерали | цілі, дійсні (`1.5`, `.5`, `1e-3`), символьні (`'A'`, `'\n'`), рядкові |
| Вбудоване | `printf` з форматами `%d %i %c %x %f %.2f %g %e %s %%` |
| Інше | коментарі `//` і `/* */`, рядки `#include`/`#define` ігноруються, тож приклади компілюються і gcc |

Семантика відповідає C: цілочисельне ділення з усіченням до нуля, `%` зі знаком діленого,
неявні перетворення `int ↔ double` під час присвоєння, передачі аргументів і `return`,
результат порівнянь і логіки дорівнює 0/1, `&&`/`||` обчислюються ліниво, блоки мають власні області видимості.

## Збірка і запуск

Потрібні `gcc`, `flex`, `bison`, `make` і `python3` (3.8+).
- Linux: `sudo apt install flex bison build-essential`
- macOS: `brew install flex bison`
- Windows: MSYS2 (`pacman -S flex bison gcc make`) або WSL

```bash
make                       # bison -d -v parser.y ; flex lexer.l ; gcc ...
./c2py examples/demo.c -t  # -t: надрукувати AST, -n: не виконувати
python3 out.py             # запустити згенерований Python
# відкрити web/index.html у браузері: дерево AST + вихідний код + Python
make run                   # усе разом на examples/demo.c
```

Програма створює:
- `ast.json` (AST у форматі JSON),
- `out.py` (результат трансляції),
- `web/ast_data.js` (дані для сторінки візуалізації).

Після цього вона виконує програму інтерпретатором.

Перевірка коректності: вивід інтерпретатора, вивід `python3 out.py` і вивід `gcc examples/demo.c && ./a.out` мають збігатися:

```bash
./c2py examples/primes.c > a.txt; python3 out.py > b.txt; gcc -w examples/primes.c && ./a.out > c.txt
diff a.txt c.txt && diff b.txt c.txt && echo OK
```

`examples/errors.c` показує, як працює семантичний аналіз: неоголошені змінні та функції, неправильна кількість аргументів.

## Візуалізація AST (`web/index.html`)

Сторінка написана на чистому JavaScript і SVG, без бібліотек. Вона працює офлайн при відкритті файлу напряму.
- Компонування дерева: ширина піддерева дорівнює max(ширина вузла, сума ширин дітей), батько стоїть по центру над дітьми.
- Клік по вузлу згортає або розгортає піддерево, переходи анімуються.
- Колесо миші змінює масштаб, перетягування зсуває дерево.
- При наведенні на вузол з'являється підказка, а відповідний рядок вихідного коду C підсвічується.
- Є вкладки «Вихідний код C» і «Згенерований Python», а також кнопка завантаження довільного `ast.json`.

## Структура

| Файл | Призначення |
|---|---|
| `lexer.l` | лексичний аналізатор (регулярні вирази → токени) |
| `parser.y` | граматика, пріоритети операторів, побудова AST у семантичних діях |
| `ast.h / ast.c` | n-арний вузол AST, друк дерева, експорт у JSON |
| `sema.c` | таблиця символів зі стеком областей, перевірки, виведення типів |
| `interp.c` | інтерпретатор: кадри викликів, значення з типом, керування потоком |
| `codegen.c` | генератор Python із збереженням семантики C |
| `main.c` | драйвер |
| `web/index.html` | візуалізатор AST |
